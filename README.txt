CÓMO SUBIR A GITHUB
-------------------
1. Ve a github.com → tu repositorio "saruxcatalogo"
2. Haz clic en "Add file" → "Upload files"
3. Selecciona TODOS los archivos de esta carpeta
4. Escribe mensaje de commit y haz clic en "Commit changes"
5. Cloudflare se actualiza automáticamente en ~1 minuto
